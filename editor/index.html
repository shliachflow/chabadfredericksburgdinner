I don't have an editor key

The key is a private password that lets this page save changes. The site owner creates it once:

  1. On GitHub, open Settings → Developer settings → Personal access tokens → Fine-grained tokens and choose Generate new token.
  2. Give it a name like "Gala editor", pick an expiry (for example 1 year).
  3. Repository access: only select repositories → chabadfredericksburgdinner.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate the token and send it privately. It can be revoked any time from the same page.
